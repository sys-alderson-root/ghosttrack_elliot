# Ghosttrack-v1.0 🕵️‍♂️

Un outil OSINT (Open Source Intelligence) éducatif développé en Python par **sys-alderson-root**. 
Il permet de collecter des informations publiques sur des adresses IP, des numéros de téléphone, des noms d'utilisateur et des emails.

## 🚀 Fonctionnalités
- 🌐 **Tracker une IP** : Pays, ville, FAI, localisation.
- 📞 **Tracker un téléphone** : Pays, opérateur, fuseau horaire.
- 👤 **Tracker un nom d'utilisateur** : Recherche sur GitHub, Instagram, Twitter, Reddit, TikTok.
- 📧 **Tracker un email** : Hash MD5, Gravatar, Have I Been Pwned.
- 🔓 **Brute Force (Local)** : Simulation de cassage de hash (MD5, SHA1, SHA256).
